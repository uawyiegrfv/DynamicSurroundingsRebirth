## 1. 萤火虫明暗闪烁缺失（26.1 bug）

**现象**：26.1 的萤火虫没有明暗闪烁（`明暗闪烁`）。

**根因**：`FireflyParticle.getLightCoords(float)` 返回 `(int)(255.0F * fade)`——裸 0..255 值，未按 packed light（sky<<20 | block<<4）编码，渲染时闪烁不可见。

**1.20.1 的修法**：`getLightColor(float)` 把 fade 映射到 15 级 block light + `LightTexture.pack(level, level)`。

```java
// 1.20.1 FireflyParticle.getLightColor
float fade = getFadeAmount(this.getLifetimeProgress(this.age + partialTick), PARTICLE_FADE_IN_LIGHT_TIME, PARTICLE_FADE_OUT_LIGHT_TIME);
int level = (int) (15.0F * fade);
return LightTexture.pack(level, level);
```

> 建议：26.1 若想恢复明暗闪烁，把 `getLightCoords` 的返回值改成 packed light（按 1.21.1 的 sky/block light 编码）。

## 2. 暴击词字幕：多人怪物伤害/治疗（26.1 缺失）

26.1 的 `CritWordHandler` 只订阅 `LivingDamageEvent.Pre` + `LivingHealEvent`。单人共享总线正常，但**多人专用服务器下，怪物的伤害/治疗只发在服务端，客户端收不到** → 不显示。

1.20.1 额外补了：
1. `MixinClientPacketListener`（`@Inject handleDamageEvent`）拦客户端伤害包，用血量差值估算伤害数值。
2. `onTick` 里追踪 48 格内实体血量，`current > previous + 0.5` 判治疗 → 绿字（仅多人生效）。

> 建议：26.1 若要多人下也显示怪物伤害/治疗，可参考 1.20.1 的这两处实现（需适配 NeoForge 的伤害/治疗包名）。

## 3. 雾跨群系突变 + 沿边界噪声式抖动（26.1 共有问题，1.20.1 已修）

**现象**：跨群系边界走，雾距离"走一格突变一下"；沿边界线走会快速远近小幅度闪。

**根因**：`BiomeFogRangeCalculator` 用 `sampleArea(pos, 6)` 按方块采样（`getOnPos()`整数），`targetScale` 是"方块级阶跃 + 噪声"信号；26.1 的 `SCALE_ADJUST=0.002` 固定步长逼近无法消除。

**1.20.1 的修法**：
```java
// 慢速低通滤波（约 1.6s 时间常数），把量化台阶 + 噪声一起滤平
this.activeScale += (this.targetScale - this.activeScale) * 0.01F;
```
（位置插值 `interpTarget` 方案试过失败——会带回噪声导致回滚。）

> 建议：26.1 把 `SCALE_ADJUST=0.002` 固定步长换成上面的 `*=0.01F` 指数滤波。代价是雾响应慢 ~1.5-2s，慢速大气效果可接受。
